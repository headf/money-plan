# 💕 我们的生活费管家（MoneyPlan）

情侣生活费记账管家，基于 Node.js + Socket.IO 实现双端数据实时同步。

## 功能特性

- 📝 收支记录：新增 / 编辑 / 删除日常开销
- 🔄 实时同步：通过 Socket.IO 实现双方数据实时联动
- 📊 统计汇总：按类别 / 时间统计消费情况
- 👫 双端共享：情侣共用一本账，消费透明

## 技术栈

- 后端：Node.js + Express + Socket.IO
- 前端：原生 HTML / CSS / JavaScript

## 快速开始

```bash
npm install
npm start
```

浏览器访问 http://localhost:3000
